Procesamiento local

GraphMyCode es una aplicación que se ejecuta íntegramente en tu navegador. Todo el análisis de código — parsing, construcción del grafo, cálculo de dependencias — ocurre localmente usando WebAssembly (tree-sitter) y la API de Web Workers.

No existe ningún servidor de GraphMyCode que reciba, procese ni almacene tu código fuente. Cuando subes un ZIP o analizas un repo de GitHub, los archivos se descargan directamente en la memoria de tu navegador y no abandonan tu dispositivo.

✓ Tu código propietario permanece en tu máquina en todo momento.

¿Qué datos se procesan localmente?

Durante el análisis, GraphMyCode procesa en tu dispositivo:

  • Archivos de código fuente del repositorio analizado
  • Metadata de imports, exports, clases y funciones extraída por tree-sitter
  • Embeddings vectoriales generados localmente por modelos de HuggingFace Transformers
  • El grafo de dependencias construido a partir del análisis

Toda esta información se mantiene en la memoria del navegador durante la sesión y se elimina al cerrar o recargar la página.

Cuando usas el chat con IA

El chat con IA es una funcionalidad opcional que requiere que configures tu propio proveedor LLM. GraphMyCode no tiene un servidor de IA propio ni accede a tus claves de API.

Cuando haces una pregunta, GraphMyCode selecciona el contexto relevante del grafo (los archivos y relaciones relacionados con tu consulta) y lo envía junto con tu pregunta al proveedor que hayas elegido:

  • OpenAI (GPT-4, GPT-4o, etc.)
  • Google Gemini
  • Anthropic Claude
  • Ollama (modelos locales, sin conexión a internet)
⚠️ El contexto de código relevante para tu consulta viaja al proveedor que hayas seleccionado. GraphMyCode no recibe ni registra estas conversaciones.

Analytics

GraphMyCode usa Vercel Analytics para recoger métricas de uso anónimas: páginas visitadas, tiempo de sesión y errores del navegador. Estos datos no contienen información personal identificable y no incluyen código ni contenido del repositorio analizado.

No se usan cookies de tracking de terceros ni herramientas de seguimiento publicitario.

Almacenamiento local

GraphMyCode puede guardar tu configuración (preferencias de proveedor IA, ajustes de visualización) en el localStorage de tu navegador. Esta información permanece en tu dispositivo y no se envía a ningún servidor. Puedes borrarla en cualquier momento desde los ajustes del navegador.

Repositorios de GitHub

Cuando analizas un repositorio público de GitHub introduciendo su URL, GraphMyCode hace peticiones directamente desde tu navegador a la API pública de GitHub para descargar el árbol de archivos. Estas peticiones están sujetas a la política de privacidad de GitHub. GraphMyCode no intermedia ni almacena estas peticiones.
